Talk (2026 edition)
-------------------

Open `talk/index.html` in a browser. No build, no server.

- `→` / space / clicker: next animation step (then next slide)
- `←`: step back · `↑` `↓`: previous / next slide
- `N`: speaker notes · `F`: fullscreen · `R`: replay animation
- Deep link: `index.html#16.3` = slide 16, step 3

Structure: `engine.js` (step/tween engine), `scenes.js` (the GC visualizations), `slides.js` (deck content + notes), `deck.js` (navigation).
